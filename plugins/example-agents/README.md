# example-agents

An agent is a Markdown file whose frontmatter names it and says when to use it. `tools` limits what it can do, so a reviewer cannot edit what it reviews. It appears as `example-agents:changelog-reviewer`.

## Try it

```text
/plugin install example-agents@example-marketplace
```

Then ask Claude to have the `changelog-reviewer` agent check a changelog entry.
