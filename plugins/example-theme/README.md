# example-theme

A theme is a JSON file in `themes/` with a `name`, a `base` preset and colour `overrides`. It appears in `/theme` under its `name`. Themes load from the experimental `themes` component, whose manifest shape may still change.

## Try it

```text
/plugin install example-theme@example-marketplace
/plugin enable example-theme@example-marketplace
/theme
```
