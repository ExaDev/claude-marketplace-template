# marketplace-maintainer

The skill a maintainer or a contributor's Claude uses to follow this repository's conventions. It is the practical form of `CONTRIBUTING.md`, and every marketplace that comes from this template ships it.

## Try it

```text
/plugin install marketplace-maintainer@example-marketplace
/marketplace-maintainer:manage-plugins
```

## Content owner

Replace this section with the team or person who owns the content of this plugin and how to propose a change. Plugins that capture how a team works are best owned by the people doing the work.
