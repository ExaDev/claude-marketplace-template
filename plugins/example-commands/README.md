# example-commands

A command is a flat Markdown file in `commands/`. It still works and is the simplest thing that can take an argument, but skills are preferred for new plugins because they can carry reference files and be chosen by Claude as well as invoked by name.

## Try it

```text
/plugin install example-commands@example-marketplace
/example-commands:about plugins
```
